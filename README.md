# AI PDF Tutor

PDF 阅读、AI 翻译与讲解，支持批注和 Windows 桌面应用。

## 软件更新（v0.2.0 起）

- 桌面版启动后自动检查 GitHub 上的稳定 Release，此后每 6 小时检查一次；也可点击工具栏的“检查更新”。
- 有新版时，入口会显示“发现新版本”，不会自动弹窗打断阅读。点击入口即可查看新版本说明。
- 点击“下载更新”，下载完成后点击“重启安装”。安装前会保存当前批注，只有你确认安装时才退出应用。
- 下载或检查失败可以重试；不会在后台自动下载、安装或切换到预发布版本。
- **v0.1.1 没有自动更新功能**：首次请从 [GitHub Releases](https://github.com/jiiaxing/ai-document-learning/releases/latest) 下载并手动安装 v0.2.0 或更高版本，以后即可在软件内更新。
- ZIP 免安装版会提供“下载安装版”与“退出并安装新版”：旧 ZIP 目录不会原地替换，安装后请从新的桌面或开始菜单快捷方式启动。

发布者：新版本需要带有同一次构建的 `latest.yml`、安装程序 `.exe` 和 `.exe.blockmap`，客户端才能更新。发布稳定 Release 后，GitHub Actions 会自动生成 Windows 安装包、ZIP 和更新元数据。若已发布非空 `latest.yml` 却缺少其他资产，工作流会停止以保护现有更新校验；请补回同次构建的原文件或发布新版本。[桌面打包与发布说明](DESKTOP_PACKAGING.md) 包含具体流程。

## 快捷键操作

## 阅读

| 快捷键 / 操作 | 效果 |
| --- | --- |
| `Ctrl` + 鼠标滚轮 | 以鼠标位置为中心自由缩放 PDF |
| `Command` + 鼠标滚轮 | macOS 环境下以鼠标位置为中心自由缩放 PDF |
| `→` / `PageDown` | 下一页 |
| `←` / `PageUp` | 上一页 |
| `↓` | 向下滚动；单页模式到页尾后翻到下一页 |
| `↑` | 向上滚动；单页模式到页首后翻到上一页 |
| 鼠标滚轮 | 连续模式正常滚动；单页模式到页首/页尾后翻页 |
| 页码输入框内按 `Enter` | 跳转到输入的页码 |

## AI 输入

| 快捷键 / 操作 | 效果 |
| --- | --- |
| AI 讲解输入框内按 `Ctrl` + `Enter` | 发送当前问题 |
| 翻译输入框内按 `Ctrl` + `Enter` | 发送当前翻译文本 |
| AI 讲解输入框内按 `Command` + `Enter` | macOS 环境下发送当前问题 |
| 翻译输入框内按 `Command` + `Enter` | macOS 环境下发送当前翻译文本 |
| 选中 PDF 文本 | 在自动功能关闭时弹出“讲解 / 翻译”操作 |
| 右键拖选页面区域 | 对圈选或框选区域进行讲解 / 翻译 |

## 面板

| 快捷键 / 操作 | 效果 |
| --- | --- |
| `Esc` | 关闭更新或设置面板、取消笔记放置或清除当前页面圈选 |
| 拖动左右分隔条 | 调整翻译栏或 AI 讲解栏宽度 |
| 显示 / 关闭翻译或讲解栏 | 原文随阅读区宽度缩放，保持当前阅读位置 |
| 分隔条聚焦后按 `←` / `→` | 微调侧栏宽度 |
| 分隔条聚焦后按 `Shift` + `←` / `Shift` + `→` | 快速调整侧栏宽度 |

## 笔记

| 快捷键 / 操作 | 效果 |
| --- | --- |
| 笔记编辑框内按 `Esc` | 结束当前笔记编辑 |
| 笔记字号输入框内按 `Enter` | 应用当前字号 |
| 笔记字号输入框内按 `Esc` | 放弃本次字号输入并还原 |
| 开启“绘制”后拖动 PDF 页面 | 绘制自由线条 |
| 开启“橡皮”后点击或划过线条 | 删除接触到的线条 |

## 布局与滚动修复

- 打开文档时，缩放比例以阅读区实际可用宽度为上限。打开侧栏、拖动分隔条或改变窗口宽度时，原文自动适配。
- 手动使用 Ctrl / Command 加滚轮仍可自由放大，并可横向滚动查看页面。
- 连续模式按动画帧合并滚动处理，并通过二分查找定位当前页；单页模式绘制完成后再替换旧页，减少翻页闪白。
- 在 Windows 下运行 `npm ci`、`npm test`、`npm run lint` 验证；使用 `npm run desktop` 启动桌面版。
